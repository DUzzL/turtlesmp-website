Donations for server hosting

Running Turtle SMP comes with costs for server hosting, the domain and related services. If you enjoy the server and have some to spare, we'd really appreciate a donation. You can do a single donation or set up a monthly payment!

Please only donate if you genuinely want to and can comfortably afford it.

Support is entirely optional. It doesn't grant perks, ranks, or any advantages on the server. You're wonderful either way!

Vote for Turtle SMP on your favourite server list. Voting is optional and has no in-game rewards.
